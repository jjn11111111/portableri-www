Technoeconomic analysis · Bobby frame

Load Relative Levelized Cost of Compute (LRCC)

A working metric for comparing the AI bubble default against KaiRis Systems — and KaiRis on Apple M2 unified memory — with equations, labeled units, and figure-ready legends.

Definition

LRCC = ( C̄cap + C̄ops + C̄net + C̄e ) / ( Q · ηload )

LRCCrel = LRCCmodel / LRCC(a)  ·  [Q] = useful agent-turns · h−1  ·  [LRCC] = USD · agent-turn−1

C̄cap
levelized capital & GPU rent [USD · h−1]
C̄ops
licensing, orchestration, ops [USD · h−1]
C̄net
network egress/ingress + hallway tax [USD · h−1]
C̄e
energy · P · t · tariff [USD · h−1]; P [W], t [h]
Q
useful throughput — consent-governed agent work [agent-turns · h−1]
ηload
load factor — fraction of capacity doing useful work [–]
Model Architecture LRCCrel Dominant cost term
(a) Current AI bubble — cloud warehouse, full-context round-trip each turn 1.00 (baseline) C̄net + C̄cap at datacenter
(b) KaiRis Systems — federated studios, bounded projection (BP), Crystal repair ~0.25 – 0.40 C̄net reduced · local ηload rises
(c) KaiRis Systems on Apple M2 · 8 GB UMA · measured instrument path ~0.05 – 0.12 C̄net ≈ 0 class · ~50× freight reduction anchors C̄e,local
